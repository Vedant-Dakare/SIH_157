2. TECHNICAL ABSTRACT
--------------------------------------------------------------------------------
The SAT-SA (SOC Alert Triage & Security Analytics) platform is an offline,
air-gapped supervisory system engineered for cyber threat intelligence, alert
triage, cryptographic audit verification, and counterfactual risk assessment
across state-monitored infrastructure.

This project achieved the comprehensive architectural and visual modernization of
the SAT-SA frontend into an authentic Government of India / National Portal
standard adhering to the Guidelines for Indian Government Websites (GIGW 3.0)
and the W3C Web Content Accessibility Guidelines (WCAG 2.1 AA). Crucially,
the entire modernization was delivered under an invariant mandate of total
backend preservation: 100% of FastAPI endpoints, DuckDB/Parquet columnar schemas,
cryptographic SHA-256 verification algorithms, and business logic remain intact.

Key Engineering Interventions:
  * Multi-Run Finding Resolution: Resolved a critical reverse-index sort inversion
    in run selection (known[-1] selecting minimal test fixture vs known[0] latest
    run), implemented multi-run fallback traversals, and added composite key
    dispatching ({entity_id}-{signal_id}), completely eliminating 404 lookup faults.
  * IEEE 754 Floating-Point Sanitizer: Engineered an in-memory recursive data
    sanitizer (_sanitize_json) to map DuckDB/Pandas NaN and Infinite floats to
    null, eliminating fatal Starlette/FastAPI serialization exceptions.
  * High-Dimensional Telemetry Signal Matrix: Synthesized an interactive 23x17
    signal heatmap blending live queue alerts, entity risk profiles, and
    deterministic telemetry fallback.
  * Axe-Core SVG Accessibility Remediation: Resolved an axe-core nested-interactive
    violation by converting SVG containers from role="img" to role="group",
    achieving 0 accessibility violations across all views.
  * Dynamic Accessibility Engine: Implemented a live rem font-scaling system
    (A-, A, A+) and responsive navigation drawer for field workstations (<1024px).
